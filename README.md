## General Introduction
因为校报格式与7714格式不一致
本项目提供：

- 📄 **北京林业大学学报引用格式** 的 CSL 文件
- 📄 **GB/T 7714 标准格式** 的 CSL 文件（作为备选）
为你的学术之路增光添彩！
## How to use it?
1. 点击本仓库的文件列表，下载你需要的 `.csl` 文件
2. 打开你的文献管理软件：
   - **Zotero**：`编辑` → `设置` → `引用` → `样式管理器` → 点 `+` 号导入下载的 `.csl` 文件。
   - **Mendeley**：`View` → `Citation Style` → `More Styles...` → 切换到 `Custom` 标签页 → 点 `+` 导入。
   - **PaperPile / Papers**：类似路径，一般在引用样式设置中都有导入按钮。
3. 在 Word 插件或软件内置的引文工具中选择刚导入的样式，开始写作。
